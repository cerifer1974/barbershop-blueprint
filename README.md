# Barbershop Blueprint

Crie uma landing page pra uma barbearia ficticia com base no prompt em anexo. Pode inventar todas as informações, logo e imagens pois tudo será substituido posteriormente.
Use as skills necessárias pra criar o melhor projeto possível.

This project was built with [Lovable](https://lovable.dev).
